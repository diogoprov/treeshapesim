# treeshapesim: Simulate Trees with Separately Controlled Imbalance and Branching Times

Simulates rooted, binary, ultrametric trees in which topological
imbalance and the distribution of branching times are set by separate
parameters. The topology is drawn from Aldous' beta-splitting model and
the internode intervals from a pure-birth process in which each of k
lineages splits at rate k^c. Because the gamma statistic depends only on
the internode intervals and the Colless index only on the topology, beta
mainly controls imbalance and c mainly controls gamma.
